# 🚀 Quick Start Guide

Get up and running in 5 minutes!

## Installation

```bash
# Navigate to the project
cd backend-mastery-os

# Run automated setup (Linux/Mac)
./setup.sh

# Or manual install
npm install
npx prisma generate
npx prisma db push
```

## Start Development

```bash
npm run dev
```

Open **http://localhost:3000** 🎉

## First Steps

1. **Dashboard** - See your progress overview
